# CreatorHub

Многостраничный учебный сайт-платформа для поиска блогеров и контент-креаторов для рекламного сотрудничества.

## Страницы

- `index.html` — главная страница: описание платформы, преимущества, шаги работы, популярные авторы, социальные сети и статистика.
- `creators.html` — каталог с поиском, фильтрами по платформе, тематике и количеству подписчиков, сортировкой и модальными окнами.
- `creator.html?id=alina` — профиль выбранного автора и форма заявки на сотрудничество. Параметр `id` выбирает профиль из демонстрационного набора данных.
- `contacts.html` — контактная информация, форма обратной связи и раскрывающийся FAQ.

## Как запустить

1. Распакуйте архив в отдельную папку.
2. Откройте папку в Visual Studio Code.
3. Запустите `index.html` через расширение Live Server (рекомендуется) или откройте файл в браузере.
4. Для просмотра других страниц используйте меню сайта.

Сайт статический, сборка и установка npm-пакетов не требуются.

## Функциональность

- Адаптивная вёрстка для компьютеров, планшетов и телефонов.
- Единая закреплённая шапка и подвал на всех страницах.
- Переключение светлой и тёмной темы с сохранением выбора в `localStorage`.
- Поиск по имени, псевдониму и тематике креатора.
- Фильтры по социальной сети, категории и диапазону подписчиков.
- Сортировка каталога по популярности и числу подписчиков.
- Модальные окна с краткой информацией об авторе.
- Динамические страницы профилей на основе параметра `id`.
- Проверка обязательных полей и email в формах.
- FAQ-аккордеон, хлебные крошки, индикатор прокрутки и кнопка «Наверх».
- Анимации появления блоков, hover-эффекты и пользовательский курсор на устройствах с мышью.

## Технологии

HTML5, CSS3, JavaScript, Bootstrap 5.3.3, Flexbox, CSS Grid, CSS-переменные и БЭМ-подход к именованию CSS-классов.

Bootstrap, Google Fonts и фотографии загружаются с внешних CDN/ресурсов, поэтому для их отображения требуется подключение к интернету. Основная логика и стили проекта находятся в локальных файлах.

## Важное примечание

CreatorHub — демонстрационный учебный проект. Имена авторов, фотографии, описания и показатели аудитории представлены как примеры. Формы проверяют введённые данные и показывают результат на странице, но не отправляют заявки на сервер и не сохраняют их в базе данных. Социальные ссылки ведут на главные страницы соответствующих платформ.
