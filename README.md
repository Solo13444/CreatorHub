# CreatorHub

Локальная учебная платформа для подбора креаторов. Откройте index.html в браузере. Библиотеки, шрифты и изображения находятся в проекте. Установка пакетов и сборка не требуются.

## Страницы

- index.html — знакомство с платформой, популярные авторы, выбор площадки, преимущества и статистика каталога.
- creators.html — 12 профилей, поиск по имени и псевдониму, фильтры, сортировка и быстрый просмотр. Выбор площадки на главной переносится в фильтр каталога.
- creator.html?id=alina — пример адреса профиля, статистика, форматы и форма сотрудничества.
- contacts.html — контакты, обратная связь и часто задаваемые вопросы.

## Движение и доступность

Три фотокарточки появляются по очереди. Центральный портрет слегка следует за указателем на устройствах с мышью. Фильтры обновляют выборку и запускают короткое появление карточек. При открытии быстрого просмотра фокус перемещается в диалог, Esc закрывает его. Включите уменьшение движения в настройках системы для статического представления.

## Устройство проекта

Разметка HTML, CSS-переменные, БЭМ, Flexbox, Grid, локальная библиотека Bootstrap 5.3.8 и JavaScript без этапа сборки. Общий интерфейс, карточки, диалоги и обработка форм находятся в js/shared.js. Каталог и профили используют js/interior.js и данные js/data.js.

Профили и показатели демонстрационные. Внешние ссылки в профилях открывают поиск по демонстрационному псевдониму. Формы проверяют введённые данные и сохраняют учебные заявки в localStorage браузера. Чтобы удалить сохранённые учебные обращения, очистите данные сайта в настройках браузера.
